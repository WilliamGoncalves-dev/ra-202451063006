O Soccer Dream é uma aplicação web responsiva, feita com React, para um projeto social fictício que conecta jovens atletas a peneiras gratuitas de futebol: lista as peneiras em cards com busca e filtro, mostra o detalhe de cada uma e oferece um formulário de inscrição com validação.

*Pré-requisitos:** Node.js (LTS) e npm. **Como rodar a Fase 2:*

```bash
git clone https://github.com/williamgoncalves-dev/ra-202451063006.git
cd ra-202451063006/pw/trabalhos/fase-2
npm install
npm run dev
```
